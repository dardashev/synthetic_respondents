# Synthetic Respondents — генерация и валидация синтетических респондентов на основе LLM

Исследовательский проект по генерации синтетических респондентов с использованием больших языковых моделей (LLM) и оценке их способности воспроизводить характеристики реальных социальных групп.

**Тема исследования:** «Сравнительный анализ методов генерации и валидации синтетических респондентов, представляющих маргинальные социальные группы».

Проект выполняется в рамках магистерской программы «Науки о данных» МФТИ.

## Цель исследования

Определить, насколько большие языковые модели способны воспроизводить ответы представителей заданных социальных групп на социологические опросники, и оценить влияние методов адаптации моделей на качество синтетических данных.

Основные исследовательские задачи:

1. Генерация ответов синтетических респондентов на основе социально-демографических профилей.
2. Сравнение распределений синтетических ответов с реальными данными.
3. Проверка сохранения статистических зависимостей между признаками.
4. Выявление латентных подгрупп и сравнение их структуры.
5. Исследование влияния промптов и параметрически эффективного дообучения (PEFT, LoRA/QLoRA) на качество генерации.

**Основная гипотеза:** адаптация LLM на данных целевой социальной группы может повысить точность воспроизведения распределений ответов и их статистической структуры по сравнению с генерацией без дообучения.

## Данные

В качестве экспериментальной основы используется **Comparative Conspiracy Research Survey (CCRS)** — международное социологическое исследование конспирологических убеждений.

- 8 101 респондент из восьми стран: Канада, США, Германия, Австралия, ЮАР, Марокко, Ливан и Бразилия.
- Социально-демографические характеристики, политические установки, психологические и поведенческие показатели.
- Шкалы конспирологических убеждений (`ID_Q32`) и конспирологического мышления (`ID_Q33`).

На текущем этапе группа с выраженными конспирологическими убеждениями используется как экспериментальный пример целевой группы.

Для выделения групп рассчитывается интегральный показатель на основе `ID_Q32` и `ID_Q33`:

- **Marginal:** верхний квартиль распределения показателя.
- **Control:** нижний квартиль распределения.

Исследовательская выборка `marginal` содержит 2 030 респондентов.

## Методология

### 1. Подготовка и анализ данных

Очистка исходного датасета, обработка пропусков, выделение целевой и контрольной групп, анализ распределений признаков.

### 2. Генерация синтетических респондентов

Для каждого респондента формируется текстовый профиль, включающий возраст, страну, пол, образование, социально-экономическое положение и другие характеристики.

Реализованы три режима генерации:

- `demography` — социально-демографический и политический профиль без указания принадлежности к целевой группе.
- `group` — профиль с указанием принадлежности к группе с повышенной склонностью к конспирологическим убеждениям.
- `individual` — профиль с дополнительными индивидуальными значениями шкал `ID_Q32` и `ID_Q33`.

Режим `individual` использует информацию о реальных установках респондента, поэтому требует отдельного контроля утечки целевых данных при оценке качества.

Генерация реализована с использованием **Llama 3 8B, vLLM и OpenAI-совместимого API**. Поддерживаются параллельная обработка респондентов, проверка формата ответов, сохранение промежуточных результатов и возобновление прерванных опросов.

### 3. Валидация синтетических данных

Для сопоставления реальных и синтетических ответов используются:

**Распределения ответов**

- Расстояние Дженсена — Шеннона (JS) по отдельным вопросам.
- Агрегированные показатели расхождения распределений.
- Визуальное сравнение распределений.

**Латентная структура**

- Выделение латентных классов методом StepMix.
- Построение модели классов по реальным данным.
- Отнесение синтетических респондентов к выявленным классам.
- Сравнение размеров и характеристик классов.

**Статистические зависимости**

- Анализ зависимостей между исходными переменными с использованием PhiK.
- Сравнение матриц связей реальных и синтетических данных.
- Оценка сохранения связей внутри латентных классов.

Сходство отдельных распределений не рассматривается как достаточное доказательство качества синтетических данных: дополнительно проверяется воспроизведение совместной структуры ответов.

## Запуск

Для работы с проектом требуется Python и среда Jupyter Notebook.

Установка основных зависимостей:

`pip install numpy pandas scipy scikit-learn matplotlib seaborn plotly stepmix phik joblib mplcursors openai tqdm jupyter`

**Анализ данных:** открыть `dataset_research_distribution_and_latent_phik.ipynb` и выполнить необходимые ячейки.

**Генерация:** запустить vLLM-сервер с совместимой инструкционной моделью, указать адрес API и идентификатор модели в `synthetic_respondents_vllm_simple.ipynb`.

Основные параметры генерации:

- `model` — идентификатор модели на сервере.
- `profile_mode` — режим построения профиля.
- `n_respondents` — количество респондентов.
- `max_workers` — количество параллельных запросов.
- `temperature` — температура генерации.
- `RUN_GENERATION` — разрешение запуска генерации.

Результаты сохраняются в каталоге `results/<run_id>/`, включая `answers.csv` и контрольные точки выполнения.
